# UI and UX design

## Purpose
Create interfaces that help users complete their goals clearly and confidently.

## Approach
1. Understand the user, task, content, context and device.
2. Inspect the current screen, routes, shared components, tokens and relevant states.
3. Consider information architecture, hierarchy, navigation and interaction options.
4. Design loading, empty, error, success, disabled and permission states where relevant.
5. Consider keyboard access, semantics, focus, contrast, reduced motion, responsive behavior and localization.
6. Implement the simplest reusable pattern that supports the experience.
7. Review against the intended user outcome and refine.

Use the lightest process that fits. A small visual correction does not need a full design specification.

## Rademan context
Persian-first RTL and mixed Persian/Latin content are important current considerations. The application includes public discovery, buyer and artist workspaces, administration and messaging. Verify actual route and component behavior before changing it. Existing brand colors and components are inputs, not immutable constraints.

## Deliverable
A design recommendation, screen/journey specification, interaction states or implementation-ready UI changes, depending on the request.
