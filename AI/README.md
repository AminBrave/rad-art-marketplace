# Rademan AI documentation

This folder contains concise project context and engineering references for people and AI contributors.

## Start here

1. Read the repository-root AGENTS.md for the short AI entry point and user-authority model.
2. Read [DEVELOPMENT-GUIDE.md](DEVELOPMENT-GUIDE.md) for the central Rademan engineering approach.
3. Open only the topic-specific reference that helps with the current task.

## AI skills

Reusable task-focused skills live in the repository's .agents/skills/ directory. Each skill has a short purpose, approach, Rademan context and deliverable. Load only what helps the task.

## Document ownership

Each topic has one canonical reference. Other documents should link to it instead of copying its rules. The user's latest explicit direction supersedes repository defaults, AI suggestions and historical records. Remove obsolete instructions when they no longer help; this folder is not an archive of past roadmaps, prompts or agent policies.
